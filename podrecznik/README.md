# Podręcznik — strony w PDF

Tu leżą strony podręcznika *Fallout: Equestria RPG* (v1.22), każda w osobnym pliku `FoE_strona_NNN.pdf`.
Służą jako źródło przy pisaniu zasad i Kompendium; nie trafiają do paczki systemu.

## Jak dodać lub podmienić strony przez przeglądarkę (GitHub)

1. Wejdź do tego folderu (`podrecznik/`) na stronie repozytorium.
2. **Add file → Upload files** i przeciągnij pliki — trafią prosto do tego folderu.
3. Na dole: zaznacz *Create a new branch…* (albo commit prosto do `main`) i **Commit changes**.

Nowy folder na GitHubie zakłada się, wpisując jego nazwę z ukośnikiem w polu nazwy pliku
(**Add file → Create new file**, np. `podrecznik/mapy/README.md`) — pusty folder nie może istnieć.
